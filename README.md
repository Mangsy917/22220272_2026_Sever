# 게임 개요
할리갈리
장르 : 보드게임
인원 : 2~4인
시간 : 제한 없음

# 게임 규칙
1. 랜덤 도형, 랜덤 숫자 구현
2. 1명이라도 보유 카드가 0이 되면 게임 종료
3. 종료 기준 카드를 가장 많이 보유한 사람이 승리

# 서버 작동 방식
1. 클라이언트의 서버 접속
2. 아이디 입력 => 아이디 유무 & 중복 로그인 확인
3. 입장 시 2명 이상 시 게임 시작 / 4명 접속 시 다른 접속 차단
4. 게임 진행
5. 한명이라도 보유 카드가 0이 되면 게임 종료 / 보유 카드 수로 1위 산정 후 브로드 캐스트로 1등 아이디 출력
6. 서버에 우승자 아이디 결과 저장

# 구현 패킷 목록
로그인 - 닉네임(string) C2S | 
로그인 결과 - 결과(bool) S2C

준비 - 준비확인 C2S | 
조작 - 카드 뒤집기 / 벨 C2S

시스템메세지 - 텍스트(string), (게임 시작 메세지, 턴 알림, 게임결과 메세지 송출) S2C | 
나온카드 전달 - 도형, 갯수 S2C

오답 - 카드-n S2C | 
게임 종료 - 승자, 추가할 카드 S2C | 
게임 결과 - S2C
